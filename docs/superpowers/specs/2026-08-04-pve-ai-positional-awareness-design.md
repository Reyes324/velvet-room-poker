# PVE AI：位置感知（positional awareness）设计文档

## 背景

用户诉求延续 2026-08-03 那轮"让机器人更接近真人"的工作。那一轮结束时明确记录了四项"本轮不做"：**位置概念**、线路连贯性、牌面纹理、心情值（见 `tasks.md` 69.20 的"明确不做"段）。用户选择先补位置。

位置是真实德扑里仅次于牌力的第二重要因素：按钮位能玩的起手牌范围比枪口位宽一大截，因为后面没人再行动、信息最全、翻后还能持续保有主动权。现在 AI 完全没有这个概念。

## 实测发现：真正的缺口在翻后，不在翻前

设计前先跑了真实 `GameEngine` 确认现状，结果推翻了最初的假设。

**翻前**（8 人桌，第一圈依次弃牌）：

```
p3 行动: liveOpponentCount=7  我后面还没说话的=7
p4 行动: liveOpponentCount=6  我后面还没说话的=6
p5 行动: liveOpponentCount=5  我后面还没说话的=5
p6 行动: liveOpponentCount=4  我后面还没说话的=4
```

两个量**恰好相等**——因为翻前第一圈里，前面弃掉的人同时从"还没弃牌"和"还没说话"两个集合里消失。也就是说，翻前的位置信息**已经隐含在现有的 `liveOpponentCount` 里**，AI 在枪口位面对 7 个对手、在按钮位面对 1-2 个，聚合弃牌权益 `p^n` 已经在事实上区分它们了。

**翻后**（6 人桌，全跟进翻牌）：

```
p1(rel庄家1) liveOpponentCount=5  我后面还没说话=5
p2(rel庄家2) liveOpponentCount=5  我后面还没说话=4
p3(rel庄家3) liveOpponentCount=5  我后面还没说话=3
```

`liveOpponentCount` **恒为 5 一动不动**，而"我后面还没说话的人数"从 5 递减到 3。翻后两个量彻底脱钩：AI 分不清"我第一个说话（最不利）"和"我最后说话（最有利）"，同一条街上每个位置在它眼里完全一样。

**结论：位置感缺失的实质主要在翻后。** 翻前虽然已隐式生效，但仍把位置作为独立概念显式传入——让它成为明确的、可测试的量，而不是依赖另一个变量碰巧等价而隐式成立。

## 核心量：`playersToActAfter`

定义：**这条街上，我之后还没行动的活跃玩家数**。

在 `PveSession.aiAction()` 里计算——从当前行动位往后遍历，统计 `status !== 'folded'` 且不在 `actedThisStreet` 里的玩家。数据全部现成（`GameEngine` 已有 `dealerIndex`、`actionIndex`、`actedThisStreet`、每个 player 的 `status`），**不需要任何引擎改动**。

选连续量而不是"早/中/晚位"分档：分档在桌型变化时语义会漂移（6 人桌的"中位"和 8 人桌的"中位"不是一回事），而这个量在任何桌型、任何街上都直接可比，单挑也天然成立（庄家/小盲翻前先说 → `playersToActAfter=1`；翻后反过来 → `0`）。

## 影响面：两处，各有正统理由

### 1. 弃牌权益（`estimateFoldEquity`）

我后面还没说话的人越多，这一注被人叫住的概率越高，靠下注直接赢下底池的机会越小。这是**纯概率事实**，与风格偏好无关。

现有的聚合模型已经是 `p^n` 的形状（n 个对手都弃牌的概率），位置要做的是把 n 从"还没弃牌的人数"修正为"还能对我这一注做出反应的人数"——翻前两者相等（所以行为不变），翻后前者恒定、后者递减（所以位置终于生效）。

### 2. 胜率实现率（`realizedEquity`）

有位置时，后面每条街我都最后行动、信息最全，同样一手牌的胜率能兑现得更多；没位置则相反。德扑里这个概念叫 **positional equity realization**，是位置价值的正统解释，也是现有 `realizedEquity()` 函数本来就在建模的东西（它已经按剩余街数和 SPR 打折，位置是同一类折扣的另一个正当维度）。

## 明确不碰：对手范围推断

**不把位置接进 `opponentRangePct` 那条链路。** 那条链路是用来推断**对手**手里有什么牌的，而位置是**我自己**的属性——混进去会污染一个正交的概念。

这条约束不是洁癖，是有代价的教训：2026-08-02 曾因为让风格调整过的胜率流进一个客观阈值判断，导致 `callingStation` 绕开池控制折扣；2026-08-03 又因为 `equityIfCalled` 在满桌下符号反了，制造出一个"看起来完美达标"的假象。**客观事实与主观调整必须分层，位置属于前者，不能和"我觉得对手有多强"搅在一起。**

## 与既有机制的共存

- **MDF 尺寸感知**（`sizePressure`）：正交。它回答"我这一注多有威慑力"，位置回答"有多少人还能对它做出反应"。两者都作用于弃牌权益，相乘即可，语义不冲突。
- **`equityIfCalled`**：正交。它是"跟我的人有多强"，位置是"我在信息上占不占优"。
- **风格偏差**（`STYLE_EV_BIAS`）：位置在风格之前施加，且只作用于客观量。风格仍只影响"面对同样的不确定性愿不愿意冒险"。

## 验收方式

**不假设，跑实测。** 位置感会让前位更紧、后位更松，对总体 PFR 的**净影响方向无法先验断定**——可能顺带把 31.6% 拉进 15-25% 目标区间，也可能不变甚至上升。

1. **单元测试**：`playersToActAfter` 在翻前/翻后、各种桌型、单挑、有人弃牌后的取值正确性；位置对弃牌权益和胜率实现率的影响方向正确（后面人越多 → 弃牌权益越低）。
2. **行为回归**：翻前行为应与改动前基本一致（两个量相等，位置显式化不该改变结果）——这是本设计"翻前隐式已生效"这一判断的直接检验，若翻前行为大幅变化说明理解有误。
3. **`pvePreflopStats.js`**（必须 `seatCount=8` 满桌判读）：记录 PFR/VPIP/翻后主动率的变化，如实报告，不为了好看而调参。
4. **`pveBalanceCheck.js`**（≥15 组，避免已记录在案的小样本假阳性）：确认四个风格没有因此崩掉。
5. **真实浏览器验证**：实际打若干手，确认无崩溃、无非法动作、牌局正常推进。

## 明确不做（本轮范围之外）

- 线路连贯性（跨街"我在讲什么故事"的记忆）
- 牌面纹理（湿/干牌面区别对待）
- 心情值（跨手牌情绪状态——用户 2026-08-03 已明确要求 AI"理性一点"，撤回过感知噪声，这一项方向相悖）
- 真正的多街前瞻（求解器级别复杂度，长期不做项）
