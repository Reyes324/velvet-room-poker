# PVE AI：下注尺寸建模与对手范围推断 设计文档

## 背景

用户反馈："怎样才能让现在的机器人更接近真人，让我们玩家打起来更真实，不会感觉到机器人经常做很傻的举动，也能聪明的根据对局和玩家去做猜测"。

排查时先验证用户实际观察到的一个现象（2♣9♦ 翻前全下），结果挖出一个比预期严重得多的问题，并且发现它跟"AI 不读下注尺寸"是同一个根因。

## 实测发现：翻前根本没有起手牌筛选

在 20bb 及以上（正常筹码深度）、翻前未面对加注的局面下，AI 对 **AA、AKs、76s、T2o、92o、72o 全部选择加注**——不是"范围偏宽"，是 100% 的牌都加注。

拆开 72o 在 20bb 的 EV：

```
弃牌权益项 = 0.45 × 30 = +13.50   ← 凭空白拿
被跟注项   = 0.55 × (0.308×90 − 40) = −6.77
evRaise    = +6.73  →  优于弃牌(0)，所以加注
```

根因：`estimateFoldEquity` 算出的弃牌权益是**恒定 0.45，与加注多大完全无关**。上面这手打的是最小加注（加到 40，对手再跟 20 就能赢 70），现实中几乎无人会弃牌，但模型认为它和推一个满池注一样能吓走 45% 的对手。这 13.5 筹码的"免费收益"盖过了烂牌被跟注后的亏损。

把先验降到 0.25 以下才能让 72o 弃牌，但那会连带砍掉所有正常诈唬，不是正确解法——**问题不在这个数字大小，在于它没有尺寸依赖**。

## 统一概念：EV 公式必须建模"池子里还剩谁、下注尺寸意味着什么"

这一轮修的是一个概念的三个面向，而不是三个独立特性：

| | 现状 | 症状 |
|---|---|---|
| **A. 自己的尺寸 → 自己的弃牌权益** | 恒定 0.45，与尺寸无关 | 翻前 100% 加注 |
| **B. 对手的尺寸 → 对手的范围** | 只看"加没加注"，不看多大 | 玩家超池，AI 拿烂牌硬跟 |
| **C. 被跟注时对手强于随机** | 开池时按"随机两张牌"算胜率 | 烂牌开池仍显示 +EV |

三者都修好，翻前范围才会自然收敛到合理形状——单修任何一个都不够（下面每一节都有实测数字佐证）。

## A. 自己的尺寸 → 自己的弃牌权益（MDF 锚定）

用最小防守频率（Minimum Defense Frequency）做锚，这是德扑标准理论，不是拍脑袋的数字。

对手需要跟 `B = opponentDelta` 才能赢下 `potSize + cost` 的底池，其理论弃牌上限即 `B / (potSize + cost)`。归一化成"满池注 = 1.0"，让现有的 `DEFAULT_FOLD_PRIOR = 0.45` 语义变为"打一个满池注时的弃牌率"（这个常量本身不用改）：

```
sizePressure = 2 × opponentDelta / (potSize + cost)      上限 1.6（≈4 倍池）
foldEquity   = 现有观测倾向 × 风格系数 × sizePressure     再走原有的 p^n 多人聚合
```

教科书自检（`sizePressure × 0.5` 即理论弃牌上限）：

| 下注尺寸 | 理论弃牌上限 | 教科书值 |
|---|---|---|
| 满池 | 0.500 | 0.5 ✓ |
| 半池 | 0.333 | 1/3 ✓ |
| 2 倍超池 | 0.667 | 2/3 ✓ |
| 最小加注 | 0.286 | —（现在才有区分度）|

**实测**：72o 的 `evRaise` 从 +6.73 → −1.43（正确弃牌），AA 仍为 +34.8（正确加注）。

## B. 对手的尺寸 → 对手的范围（含两极化）

在现有"按观测到的加注频率算基础宽度"之上再乘一个尺寸系数——疯子的满池注和岩石的满池注含义不同，这一层保留：

| 对手下注/底池 | AI 假设的范围 |
|---|---|
| ≤ 1/3 池 | 前 60% |
| ~半池 | 前 45% |
| ~满池 | 前 30% |
| > 1.5 倍池 | **两极化**：前 12% + 后 15%，中间牌力挖空 |

超池采用真正的两极化建模（而非继续单调收窄），因为真实德扑里超池是"要么坚果要么纯诈唬"。**实测证明这个区别是实质性的**（公共牌 Th 7c 2d，对比"单调前20%"与"两极化12%+15%"）：

| 我的牌 | 单调前20% | 两极化 | 差值 |
|---|---|---|---|
| 强牌 TT（中三条） | 0.955 | 0.964 | +0.009 |
| 中等 T9（顶对弱踢） | 0.667 | 0.747 | **+0.081** |
| 空气 K4 | 0.210 | 0.326 | **+0.116** |

方向完全符合理论：坚果几乎不受影响，**中等牌力面对超池反而应该更敢跟**（因为对手范围里有一块是纯诈唬）。若只做单调收窄，AI 会对超池过度弃牌——那是另一种不真实。

实现上，两极化在现有结构里很便宜：`HAND_CLASSES` 已按分数降序并带累计组合数 `cumBefore`，取"前 X% ∪ 后 Y%"只需新增一个 `getPolarizedRangeSet(topPct, bottomPct)`，`computeEquity` 的拒绝采样循环一行都不用改。

**接口**：`computeEquity` 的 opts 新增可选 `opponentBottomPct`（默认 0 = 当前的单调行为，完全向后兼容，现有测试不用改）。`opponentRangePct` 语义变为"顶部百分比"。

## C. 加注的选择效应

`evCall` 和 `evRaise` 面对的是**不同的对手范围**，因此要用两个不同的胜率：

- `evCall`：对手已经下注了 → 用 B 推断出的范围
- `evRaise`：会来跟我加注的人，牌力必然强于随机 → 用"跟注者范围"（约前 35%）

现状是只算一次胜率、两个分支共用，等于假设"跟我加注的人拿的是随机两张牌"。

**实测**（对随机 vs 对前 30%）：

| 起手牌 | vs 随机 | vs 前30% | 差值 |
|---|---|---|---|
| AA | 0.839 | 0.836 | −0.003 |
| JTs | 0.574 | 0.454 | −0.120 |
| T2o | 0.417 | 0.308 | **−0.108** |

强牌几乎不掉、烂牌掉很多——正是区分开池范围所需的差异。补上这一项后 T2o 的 `evRaise` 变为 −6.2（正确弃牌），AA 仍为 +34.2。

**性能**：多算一次胜率实测 +15ms，而 AI 每步本来就有 300ms 起的拟人思考延迟，占比 4.9%，可忽略。

**接口**：`pickAction` 新增可选 `equityIfCalled`，默认等于 `equity`（向后兼容，现有测试不用改）；`PveSession.aiAction()` 算两次胜率分别传入。

## 与现有机制的关系

**与池控制折扣（`POT_CONTROL_DISCOUNT = 0.6`）**：该折扣是 2026-08-02 为了压住"中等牌力 `evRaise` 微微为正就持续下注"而加的，本质是**缺失风险模型时的代理**；组件 A 是同一个病根（弃牌权益被高估）的正解。两者叠加有把 AI 压成过度保守的风险。

**处理方式：不预先假设，用数据决定。** A 落地后，跑同一组诊断对比"折扣保留 / 减弱 / 移除"三种情况，按 VPIP/PFR 和风格平衡的实测结果决定其去留，并把结论记录进 SDD。

**与风格偏差（`STYLE_EV_BIAS`）**：沿用 2026-08-02 那次踩过的坑的教训（`callingStation` 曾靠 `equityMultiplier` 把 65% 胜率拉到 71.5%、跨过阈值绕开池控制折扣）——

> **范围与尺寸这类客观事实，一律用真实 `equity` 判断；风格只影响"面对同样的不确定性愿不愿意冒险"（即 `varianceScale`/`foldEquityMultiplier` 这一层），绝不让风格滤镜改变"对手到底有多强"的判断。**

具体：B 和 C 计算的是客观胜率，`styledEquity` 在其之后统一施加于两个胜率值。

## 验证方式

1. **单元测试**：`sizePressure` 对照教科书值（满池 0.5 / 半池 1/3 / 2倍池 2/3）；两极化范围集合的构成正确性。
2. **翻前范围回归测试**（本轮的招牌行为）：20bb 未面对加注时，断言 AA/KK/AKs 加注、72o/92o/T2o 弃牌。
3. **VPIP / PFR 量化**：新增诊断脚本统计 AI 的入池率与翻前加注率。真人水准 PFR 约 15-25%，当前是 100%。
   - **成功判据**：PFR 落入合理区间，**且不能矫枉过正**——AI 仍需保持正常的诈唬频率，不能变成什么都不敢做的岩石。这条双向判据是本轮的主要验收标准。
4. **风格平衡回归**：用现有 `server/scripts/pveBalanceCheck.js` 复跑，确认四个风格没有因为这轮改动而崩掉。注意该脚本注释里已记录的小样本假阳性坑——出现"每组同方向"标记时先跑 15+ 组再下结论。
5. **真实浏览器验证**：按项目惯例，实际打几手确认体感，不只看数字。

## 明确不做（这轮范围之外）

以下三项在讨论中识别出来但**明确推迟**，避免这轮范围失控：

- **位置概念**：AI 不知道自己先说话还是后说话，每个座位打同一套范围。
- **线路连贯性**：AI 没有"我这手牌在讲什么故事"的跨街记忆，可能翻牌加注、转牌过牌、河牌又拿空气下注。
- **牌面纹理**：湿润/干燥牌面下的下注尺寸与延续意愿相同，也不会按牌面重新调整对手范围。

此外仍然不做真正的多街前瞻（求解器级别复杂度，`2026-08-02-pve-ev-driven-ai-design.md` 已列为长期不做项）。
